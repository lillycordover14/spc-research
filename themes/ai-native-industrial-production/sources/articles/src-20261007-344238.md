Spherene Simulation Tool Enables In-Platform Structural Analysis for Additive Manufacturing


            Spherene AG introduces Simulation in sphereneNxt v2.0.0, a browser-based linear static structural analysis capability for validating internal part architectures without leaving the design environment.

Spherene AG
 has announced that Simulation is available in sphereneNxt v2.0.0, the company's browser-based engineering platform for designing the internal architecture of parts for additive manufacturing. The first release brings linear static structural analysis directly into the platform, so engineers can design an internal structure and test it in the same place.

Validating a structure has typically meant exporting geometry to a separate analysis tool, adding time and cost to every iteration. Simulation is designed to close that gap. Engineers can run it before computing an infill to see where a design carries load and guide the structure, or run it afterward to verify the generated part meets defined requirements.

What engineers can do with Simulation:

Run linear static structural analysis in the browser, with no export to a separate tool

Analyze ADMS, TPMS and beam structures, as well as the envelope itself

Predict stress and displacement for a defined set of constraints and loads

Build one or more load cases from a full range of constraints and loads, and target them precisely by selecting nodes, facets, surfaces, planes or edges

Mesh with linear or quadratic tetrahedral elements, refine locally and run a built-in mesh-quality check before solving

Choose between an iterative and a direct solver to match the job

Review displacement and stress, analyze results across selected regions and extract a point map based on the results

Simulation reflects Spherene's focus on what happens inside a part. While much of the additive manufacturing industry concentrates on external geometry, Spherene specializes in the internal architecture, where the company says meaningful gains in weight, material efficiency and mechanical performance are still to be made. Bringing analysis into the same platform means designing that structure and validating it now happen together.

"Engineers should not have to leave their design environment to find out whether a structure holds up," says Claudio Nessi, CEO of Spherene AG. "With sphereneNxt, they design the inside of a part and test it in the same place. That is where we believe the next gains in additive manufacturing will come from: fewer iterations, faster decisions, and parts that perform as designed."

Simulation launches as the first phase of a broader analysis capability in sphereneNxt, with further modules to follow. Simulation is available to sphereneNxt users from September 28, 2026, at nxt.spherene.io.

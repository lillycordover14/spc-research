Laminar Research Releases X-Plane 12.4.4 Beta 5
October 21, 2026
Olai Dreisbach
X-Plane
Laminar Research 
released
 Beta 5 of the X-Plane 12.4.4 update yesterday, which includes more bug fixes and improvements, this time related to weather, graphics, and various plugin compatibility issues.

X-Plane 12.4.4 is an upcoming update that will improve many parts of the XP12 SDK, among other changes. The latest beta candidate has resolved an issue in which real-world weather could stop updating after being enabled mid-flight, resulting in no clouds, as well as problems with weather and lighting when synchronising with external visual systems. 

Real-world weather is also now recorded during replays, and the bug that caused clouds to disappear when entering replay mode has been fixed.

Laminar has fixed flickering night lighting in densely populated areas, which affected the opacity of scenery objects, and has improved curved road ramps and junctions.

As for the SDK itself, Beta 5 has removed the 250-dataref limit per plugin, and a drawing issue affecting OpenGL code has been resolved. OpenXR can no longer be activated at startup with VR disabled, and the weather radar’s sweep width will no longer clear the entire display.

Changelog

General

X-Plane no longer shows an error for a leading slash in a library.txt path

Graphics Core Engine

Fixed flickering lights at night in high-density areas

Fixed an error where the 
ATTR_albedo_opacity
 state was not reset at end of an object, causing its opacity to carry over to other objects using the same shader (XPD-14008)

Scenery

Improved curved ramps and cloverleaf loops at shallow-angle junctions

Weather

Fixed real-world weather freezing after switching to it mid-flight: no clouds appeared and the weather stopped updating, even though haze, visibility and wind changed as expected

Fixed an error synchronizing real-world weather with external visuals

Fixed an error synchronizing lightning strikes with external visuals

Fixed X-Plane aborting when an external visual disconnected

Fixed an issue where initial terrain and runway snow was not set correctly when using static weather

Fixed an issue where the visibility settings had no effect on lights at night

Weather Radar

Changing the weather radar sweep width no longer blanks the whole display: only the areas outside the new sweep are cleared

Replay System

Real-world weather is now recorded in replays

Fixed an error where clouds briefly disappeared after entering a replay with real-world weather enabled

VR

OpenXR is no longer activated at startup when VR is not enabled

SDK

Fixed an issue where drawing a line using OGL_lines could lead to a zero-length line

Removed the hard limit of 250 datarefs per plugin (XPD-18443)

X-Plane 12.4.4 Beta 5 is available via the public beta channels on Steam and X-Plane Installer.

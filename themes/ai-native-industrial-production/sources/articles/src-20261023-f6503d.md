Highlights
Ramp developed its internal AI agent harness, Laminar, in six weeks.
Laminar centralises execution, sandboxing, observability, and async workflows for all Ramp agents.
LangChain CEO Harrison Chase praised Ramp's design, noting a shift in agent infrastructure.
LangChain's Open SWE cut LLM inference costs by 64 per cent using in-harness model routing.
 
Ramp
, a fintech company, built its internal 
AI agent harness
 named 
Laminar
 in six weeks, according to an engineering blog post. The company had spent months evaluating managed agent APIs, open-source frameworks, and third-party platforms. Ramp concluded that an in-house build would offer better alignment and faster development.
Laminar centralises agent execution, sandboxing, observability, and asynchronous workflows. Sam Kronick, the Ramp engineer behind the platform, wrote that building in-house provided stronger alignment to the company's goals. It also offered flexibility to switch models based on cost, speed, and performance.
LangChain
 CEO 
Harrison Chase
 praised Laminar's design choices in an X post, highlighting model independence and observability. He also pointed to similar work underway in LangChain's Deep Agents project. Ramp's approach separates agent sessions from sandboxes, storing conversation history and execution state independently.
Laminar uses non-blocking asynchronous agents by default, a feature Chase described as the future of agent design. The platform also includes a Connectors Service for centralised authentication, credentials, access controls, and tool execution. LangChain is exploring comparable features for managed Deep Agents.
Optimising inference costs
LangChain's Open SWE, an open-source coding agent, uses a model router within its harness. This router assigns one of three models based on expected task complexity. It sends simpler tasks to GLM-5.3-Flash and more demanding requests to GPT-6 Astra.
This routing cut median large language model (LLM) costs by 64 per cent across 973 agent threads. Costs dropped from $2.61 to $0.94 per thread compared with using GPT-6 Astra for every task. The savings did not significantly affect performance, with merged pull request rates remaining consistent.
Ramp noted that agents generated all of Laminar’s initial code, with experienced engineers guiding the architecture. However, the company has not published operating-cost comparisons or benchmarks against competing platforms. This makes it difficult to assess whether building in-house is cheaper than using existing frameworks.

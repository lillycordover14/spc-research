Laminar Research Releases X-Plane 12.4.4 Release Candidate 1
October 29, 2026
Olai Dreisbach
X-Plane
Following several beta releases, Laminar Research 
has shipped
 X-Plane 12.4.4 Release Candidate 1, another step closer to the full 12.4.4 release.

The new Release Candidate continues work on the so-called “SDK Update” and primarily addresses bugs affecting plugin functionality, avionics, and overall stability.

A particular focus in this update is X-Plane 12’s new browser-based avionics functionality. Laminar has fixed many issues involving cockpit displays, including crashes when browser-based avionics were initialised without other avionics running, incorrect greyscale rendering, and problems entering text on Windows.

Mouse interactions with browser-based avionics in 3D cockpits have been corrected, and plugin browser windows will no longer automatically take keyboard focus when opened.

Flickering dynamic scenery lights, an issue with the overspeed governor on turboprop engines, and incorrect electrical load indications in the default Beechcraft King Air C90B have also been solved, Laminar Research writes.

Changelog

Beechcraft King Air C90B

Fixed an error where the DC LOAD and DC VOLTS indicators displayed an extremely high current load (XPD-18558)

Graphics Core Engine

Fixed tile light flickering of scenery dynamic lights

Systems

Fixed overspeed governor for turboprop engines (XPD-18531)

SDK

Plugin browser windows will no longer take the keyboard focus on creation (XPD-18557)

Fixed a crash when a browser avionics device was drawn while no other avionics were drawing, for example in a cold and dark cockpit or when

its URL was set before the first flight (XPD-18551)

Fixed browser avionics devices on 3-D objects sometimes showing in greyscale (XPD-18551)

Fixed typing into text fields on browser avionics devices on Windows (XPD-18551)

Clicks on avionics devices in the 3-D cockpit now release at the correct position, so clicks reach browser pages. A click cancelled by X-Plane, for example when its popup closes while the button is held, now reaches the device as a cancel. Plugin mouse callbacks receive it as xplm_MouseUp at -32768, -32768 (XPD-18551)

Fixed a possible crash drawing plugin-placed objects with scenery shadows enabled

Documented that XPLMTakeAvionicsKeyboardFocus(NULL), not XPLMTakeKeyboardFocus(NULL), releases a device’s keyboard focus (XPD-18551)

Documented that XPLMDrawString, XPLMDrawNumber, XPLMDrawTranslucentDarkBox and XPLMSetGraphicsState only work in OpenGL drawing callbacks, not Panel Graphics ones (XPD-18552)

X-Plane 12.4.4 Release Candidate 1 is now available, along with release candidates for XLua 2.0.0 and X-Plane SDK 440.

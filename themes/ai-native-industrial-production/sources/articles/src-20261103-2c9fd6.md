3dSen emulator that transforms NES games into 3D voxel dioramas v2.0 brings huge changes

3 Nov 2026 at 8:38 am UTC
 

								By 
Liam Squires-Hand

 
0 comments

3dSen is just magic. An emulator that turns retro NES games into 3D voxel dioramas across flat PC gaming and VR has a huge new release out with 2.0. Note: the PC / VR versions are separate.

There's a big interface refresh, overhauled gamepad controls, the PC version has an upgraded Native Linux version, smoother loading times, enhanced visuals and so much more. It really is impressive what they've been able to do with this, with 100s of games now supported. Really helps give a whole new feeling to retro gaming.

Key Changes

Redesigned interface:
 Browse games in list or grid view with cover art, search and filter your library, and mark favorites.

Gamepad menu navigation:
 Navigate the whole interface with a gamepad, with a built-in on-screen keyboard for search.

Resume where you left off:
 When you reopen 3dSen, choose Continue to resume your previous game or Discard to start fresh.

Enhanced visual style:
 Customize reflections, shading, pixel shadows, voxel grooves and world curvature. The effects start switched off, so turn on the ones you like in Settings > Visual Effects and see each change in a live preview of the paused game. The Classic style remains available.

Retina render mode:
 A whole new way of sub-voxel modeling. Instead of building every pixel as a block, Retina sculpts smooth, rounded surfaces that cut through the voxels. Turn it on in Settings > Display > Render Mode.

Anti-aliasing:
 Choose Off, 2x or 4x. The default is 2x.

Run Ahead:
 On by default, it reduces input delay for more responsive gameplay.

Soft Reset:
 Restart the game as if pressing Reset on the original console. Some games keep scores or other data after a soft reset.

Mouse camera control:
 Drag with the right mouse button to turn the camera.

Rendering fixes:
 Fixed thin cracks, dark dots and dark lines between 3D tiles.

Smoother loading:
 Fewer stutters when loading games.

Safer saving:
 Settings are preserved if the app closes abruptly.

Camera fix:
 Zooming in no longer makes the camera spin.

Profile fixes:
 Fixed issues in the Super Mario Bros., Punch-Out!! and Final Fantasy profiles.

Other fixes and optimizations:
 Improvements to emulation, audio, rewind, save-state handling, performance and memory usage.

64-bit Windows build:
 The Windows version has moved from 32-bit to 64-bit.

Native Apple Silicon support:
 The macOS version now runs natively on both Apple Silicon and Intel Macs.

Steam Deck:
 The native Linux version runs a lot better now and is recommended over the Windows version through Proton. To use it, open the game's Properties > Compatibility, tick "Force the use of a specific Steam Play compatibility tool" and choose Steam Linux Runtime.

VR-specific changes

OpenXR:
 3dSenVR now runs on OpenXR, the common standard for PC VR. It works with SteamVR headsets, Meta Quest (Link, Air Link or Virtual Desktop) and Steam Frame.

The new menu in VR:
 Point with either controller and pull the trigger to click. The left stick moves around, B / Y goes back. An idle or switched-off controller hides its ray.

VR controller bindings:
 Remap any VR controller button in Settings > Controls > VR Controllers, including Rewind, Fast Forward, Quick Save and Quick Load.

Steam Frame controller support:
 The D-pad works out of the box, with a layout like an Xbox controller.

Scene Scale tab:
 Adjust the size of the game world from a dedicated VR tab at the top of Settings.

Comfort:
 The game sits at a more comfortable distance after a view reset, and the in-game score and status bar moves back with it. Messages like "Quick Save" appear at a comfortable distance and follow your Scene Scale.

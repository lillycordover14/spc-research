Google has donated gVisor, Agent Substrate, and OpenRL to the Cloud Native Computing Foundation (CNCF). This move aims to establish Google's AI agent infrastructure projects as industry standards, similar to Kubernetes' success for containers.

Highlights
Google donated gVisor, Agent Substrate, and OpenRL to the CNCF.
The move aims to make Google's AI agent stack an industry standard.
gVisor improves container security for untrusted AI agent code.
Agent Substrate 1.0 is now available on Google Kubernetes Engine.
 
Google has donated three core AI agent infrastructure projects, 
gVisor
, 
Agent Substrate
, and 
OpenRL
, to the 
Cloud Native Computing Foundation
 (
CNCF
). This move, confirmed by Drew Bradstock, VP of product management, 
Kubernetes
 and orchestration at Google, aims to establish these projects as industry standards, similar to Kubernetes' success for containers.
The donation addresses growing concerns about the security of autonomous 
AI agents
. These agents can execute code and interact with external systems, posing security challenges. OpenAI, for example, cited sandboxes like gVisor as crucial for limiting damage from exploited Linux kernel vulnerabilities.
Key Projects and Their Functions
gVisor, open-sourced in 2018, enhances 
container security
 by using a lightweight kernel in user space to intercept application system calls. Major AI companies, including Anthropic and OpenAI, use gVisor to isolate code execution.
Agent Substrate helps run large numbers of autonomous agents efficiently. It introduces an additional runtime layer on Kubernetes, allowing agents to be suspended when inactive and resumed as needed. Google has officially released Agent Substrate 1.0, making it generally available on Google Kubernetes Engine (GKE).
OpenRL focuses on reinforcement learning, enabling developers to fine-tune AI models on their Kubernetes infrastructure. It coordinates training and evaluation processes and integrates with Agent Substrate for isolated training environments secured by gVisor.
Vendor-Neutral Governance
The shift to CNCF governance is expected to encourage wider industry participation and adoption. Etienne Perot and Jing Chen, gVisor contributors at Google, believe independent governance will accelerate gVisor's growth. They also outlined plans to move development and testing infrastructure outside Google and introduce a governance model preventing single-company control.
Previously, upstream Linux maintainers declined to merge gVisor performance improvements while the project was owned by a single vendor. Bradstock stated that vendor-neutral ownership allows cloud providers, hardware vendors, and independent software companies to participate equally in the growth of agentic workloads.

Key Highlights
CNCF welcomes 12 new Silver members, expanding its community across sovereign cloud, AI agent infrastructure, security and financial services.
As organizations move AI agents into production, new members bring expertise in open infrastructure that supports data sovereignty, operational visibility, security and control.
Enterprises, developers and platform teams gain access to a broader ecosystem of cloud native technologies and expertise to securely build, deploy and manage AI workloads across environments.

This cohort, spanning sovereign cloud and hosting, AI agent infrastructure, container security, and financial services, broadens the ecosystem of organizations building and operating production AI.

As organizations move AI agents from pilot to production, platform teams face rising demands for data control, operational visibility, and software supply chain trust. CNCF's newest members reflect that shift, bringing domain expertise and technology built to run agentic workloads on open, portable infrastructure.

About Cloud Native Computing Foundation
Cloud native computing empowers organizations to build and run scalable applications with an open source software stack in public, private, and hybrid clouds. The Cloud Native Computing Foundation (CNCF) hosts critical components of the global technology infrastructure, including Kubernetes, Prometheus, and Envoy. CNCF brings together the industry's top developers, end users, and vendors and runs the largest open source developer conferences in the world. Supported by nearly 800 members, including the world's largest cloud computing and software companies, as well as over 200 innovative startups, CNCF is part of the nonprofit Linux Foundation.

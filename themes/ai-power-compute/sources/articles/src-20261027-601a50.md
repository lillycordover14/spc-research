Google Find Hub is preparing to fix one of Android tracking's biggest headaches
Upcoming features reveal new ways to stop unwanted alerts while still keeping track of separated items.
By 
Aamir Siddiqui
AssembleDebug
•
Oct 27, 2026
 — 4:57 AM ET
•

TL;DR

Google Find Hub code reveals that “Left-Behind” separation reminders are in development for item tags, headsets, and other supported accessories.

Users will be able to set trusted exclusion zones to silence separation alerts at specific places, such as home, either globally or per device.

Upcoming controls will let users move notification and reverse-ringing settings between devices without unpairing and re-enrolling accessories.

As Google gears up for the November 11 first sale of its long-awaited 
Pixel Tag
, the company is actively laying the groundwork to ensure its tracking ecosystem is ready for it. Google has been working on 
Left-Behind reminders for the Find Hub ecosystem
, and the feature made an appearance in the recent 
October Google Play Services Update
 changelog as well. We’ve now spotted more clues in Find Hub that indicate further progress on these key tracking accessory features, and they should put your mind at ease if you were planning to buy the Pixel Tag.

You’re reading an 
Authority Insights
 story. Authority Insights brings you all the latest exclusive reports, app teardowns, leaks, and in-depth tech coverage from the 
Android Authority
 team that you won’t find anywhere else.

In Find Hub v3.1.787-04, we’ve found code suggesting that Left-Behind reminders will work not only with item tags but also with headsets and other supported accessories (“item”).

Code
Copy Text
<string name="device_details_lbr_section_fragment_title">Notify when left behind</string>
<string name="device_panel_lbr_button_title">Notify when left behind</string>
<string name="device_details_lbr_section_fragment_headset_subtitle">Receive a notification when this headset is separated from your phone</string>
<string name="device_details_lbr_section_fragment_item_subtitle">Receive a notification when this item is separated from your phone</string>
<string name="device_details_lbr_section_fragment_tag_subtitle">Receive a notification when this tag is separated from your phone</string>

Users will be able to set Left-Behind reminders for multiple items and, as you’d expect in a tracker ecosystem, will be notified when any are left behind.

Code
Copy Text
<string name="adm_multiple_items_left_behind_default_header">Left behind items</string>
<string name="lbr_notification_text_no_address_multiple_items">These items are no longer detected near you. Tap to see their last location.</string>

Users will also be able to set up exclusion zones for these notifications, so you don’t end up receiving a barrage of notifications when you intentionally leave things behind at trusted locations, like your home.

Code
Copy Text
<string name="add_location_text">Add location</string>
<string name="lbr_delete_location_dialog_message">You'll be notified when you leave your device at this location</string>

Users will be able to set up a general exclusion zone for all devices, or exclusion zones for specific items too:

Code
Copy Text
<string name="lbr_exclusion_zone_dialog_for_all_devices">For all my devices</string>
<string name="lbr_exclusion_zone_dialog_for_this_device">For this device</string>
<string name="lbr_exclusion_zone_dialog_message">You won't get notified when you leave your devices or items at this location</string>
<string name="lbr_exclusion_zone_dialog_title">Don't notify at this location?</string>

Google is also working on the ability to move Left-Behind notification settings of a particular tag, headset, or item to a different device, possibly accommodating instances where you’d want specific notifications on your tablet or laptop rather than your phone. This could also be useful for people who use multiple phones, want to manage accessory alerts on a different device, or are changing phones.

Code
Copy Text
<string name="lbr_move_all_headset_settings_dialog_title">Move all settings for this headset?</string>
<string name="lbr_move_all_headset_settings_dialog_message">Left-behind notifications for this headset are currently being shown on %1$s. Would you like to move them to this device?</string>
<string name="lbr_move_all_item_settings_dialog_title">Move all settings for this item?</string>
<string name="lbr_move_all_item_settings_dialog_message">Left-behind notifications for this item are currently being shown on %1$s. Would you like to move them to this device?</string>
<string name="lbr_move_all_settings_dialog_title">Move all settings for this tag?</string>
<string name="lbr_move_all_settings_dialog_message">Left-behind notifications for this tag are currently being shown on %1$s. Would you like to move them to this device?</string>
<string name="lbr_move_all_settings_dialog_move">Move</string>
<string name="lbr_moving_headset_settings">Moving headset settings…</string>
<string name="lbr_moving_item_settings">Moving item settings…</string>
<string name="lbr_moving_tag_settings">Moving tag settings…</string>

Note that the above-mentioned strings describe only moving notification settings, not necessarily the transfer of ownership of the tracker or pairing data.
Similar to Left-Behind notifications, the reverse ringing feature (the ability for your tracker to ring your phone) will also support moving settings between devices:

Code
Copy Text
<string name="reverse_ringing_button_title">Ring this phone</string>
<string name="reverse_ringing_title">Ring this phone</string>
<string name="reverse_ringing_subtitle_in_range">If you can't find your phone, press your tag's button twice to make it ring:</string>
<string name="reverse_ringing_subtitle_out_of_range">You need to have the tag with you before you can change this setting</string>
<string name="reverse_ringing_enable_error_message">Can't turn on reverse ringing. Try again.</string>
<string name="reverse_ringing_disable_error_message">Can't turn off reverse ringing. Try again.</string>
<string name="reverse_ringing_transfer_dialog_title">Transfer all settings for this tag?</string>
<string name="reverse_ringing_transfer_dialog_message">This tag is currently set to ring %1$s. Would you like it to ring this device instead?</string>
<string name="reverse_ringing_transfer_dialog_positive_button">Transfer settings</string>
<string name="reverse_ringing_transfer_error_message">Can't transfer 'Ring this phone' settings. Try again.</string>
<string name="reverse_ringing_moving_tag_settings">Moving tag settings…</string>

The ability to move settings across devices will save users the trouble of unpairing and re-enrolling their trackers and accessories just to get the right feature set to appear on the right devices.
With the Pixel Tag’s retail debut just around the corner, bringing these controls natively into Find Hub should give Android’s item-tracking network the feature parity it needs to challenge competitors like Apple’s Find My network.

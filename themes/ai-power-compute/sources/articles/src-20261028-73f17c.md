Discord will let public server messages be discoverable in Google Search&nbsp;&nbsp;Mashable

[page text]
Discord is going public with new Server Web Pages that will allow Google to index public server discussion for search.

Credit: MAURO PIMENTEL / AFP via Getty Images

Finding good 
Discord
 servers relevant to your interests can be tough unless you sift through Discord's own database or get an invite to one.
The popular messaging and chat service is looking to solve that problem with an obvious yet big change to the platform. Discord will now make public servers discoverable through 
Google Search
.
On Tuesday, Discord 
announced
 that starting Nov. 16, 2026, all Discoverable Servers will receive a Server Web Page. These public Server Web Pages will include summaries of discussions happening in that public server. In addition, starting in mid-December, some messages within these servers will be made publicly accessible on the Server Web Page. There will be no need for visitors to join the server or even have a Discord account in order to see these messages.

On Discord, users can join public servers or private servers, which require an invite. Public servers can also be Discoverable Servers, meaning they are listed in Discord's searchable database of 63,000 Discoverable Servers, which anyone can join.
However, Discover servers, even Discoverable Servers, are not listed in Google Search, as servers don't have a public web page for Google to index. While public servers are open to anyone, users 
must
 join with their Discord account to see messages and discussions.

There are many reasons for Discord to make this change. In its announcement, the company explained how it will help some of its main user types — indie game developers, fandoms, and content creators — grow their communities and more easily spread their work. 
Other community platforms like 
Reddit
 have long benefited from search engine traffic as discussions on the platform tend to rank well for various user search queries on Google. Discord could also benefit from this.
However, Discord seems to be aware that some users on the platform have long valued its privacy stance. The company announced that both server owners and users on a server can opt out of making their content searchable by search engines.

Discord server admins can opt out of specific channels starting today, before anything goes live on Nov. 16, 2026. Admins can go to Server Settings > Web Presence on their public server and choose which channels to make searchable. Admins can opt out of every one of their server's channels. If an admin does not opt out, however, all public channels will be added to the Server Web Page when it goes live next month. Admins can also choose to turn off channel summaries on their Server Web Page.
In addition, users can opt out of having their messages displayed on the Server Web Page. Discord users can simply go to User Settings, then Data and Privacy, and then change their Channel Messages settings. Users cannot opt out of having their messages used in Channel Summaries on Server Web Pages. However, usernames and avatars won't be shown next to messages on these public Server Web Pages.
Private servers and DMs will remain completely private on Discord. Users do not need to change any settings for these features.

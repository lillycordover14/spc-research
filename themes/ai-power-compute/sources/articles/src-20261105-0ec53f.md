                            SUPER MICRO COMPUTER, INC.                        
+10.53%
Super Micro Computer Inc. announced a new KV cache storage solution with IBM and NVIDIA. The KV cache solution integrates Supermicro Petascale storage servers, IBM Storage Scale software, NVIDIA Dynamo inference software, and NVIDIA Spectrum-X Ethernet switches. Performance testing shows that the KV cache solution reduces Time-to-First-Token (TTFT) for long-context windows compared to systems with no KV cache.
Customers can dramatically improve inference efficiency through higher GPU utilization, throughput, and infrastructure scalability. The joint solution integrates Supermicro Petascale all-flash storage servers using AMD EPYC 9005 Series processors, IBM Storage Scale software, along with NVIDIA Dynamo inference framework software and Spectrum-X Ethernet networking. Together, these technologies can dramatically reduce the time it takes AI models to begin generating a response, a critical advantage as enterprises adopt agentic and long-context AI workflows.
Extending KV cache capacity beyond local GPU memory can improve GPU utilization and inference throughput, while enabling high availability of KV cache content and non-disruptive scaling of KV cache capacity. The result is a more scalable, resilient inference architecture that delivers faster, more responsive AI experiences. Inference workloads consist of two phases: prefill and decode.
During prefill, input text is converted into tokens and processed by the LLM to generate the intermediate key-value (KV) states needed for inference. By storing these previously computed KV states in a persistent KV cache, the system can reuse them instead of recomputing the same context for subsequent requests. Agentic workflows, coding assistants, long-context RAG, multimodal AI, and multi-turn applications can generate substantial KV state as they process large codebases, documents, conversations, images, and other context, quickly exceeding GPU and CPU memory and driving the need to offload KV cache to high-capacity, shared network storage.
The KV cache solution from Supermicro, IBM, and NVIDIA provides this persistent storage layer, helping improve inference efficiency, throughput, and scalability while reducing redundant computation. Key customer benefits of the KV cache solution include joint solution validation, dramatically faster and more consistent inference performance, higher GPU utilization and throughput, enterprise resilience and trusted AI operations, validated turnkey AI infrastructure, and accelerated deployment services. In joint testing Supermicro and NVIDIA, with a 120-billion-parameter LLM, persistent KV cache delivered up to 56x faster TTFT at 130,000-token prompts.
As input length increased from 30,000 to 130,000 tokens, TTFT increased by only 0.377 seconds with KV cache, compared with 29.55 seconds without it, enabling more consistent performance for long-context workloads. By keeping frequently reused context available outside GPU memory, the solution helps reduce GPU idle time, increase inference throughput, and support greater concurrency without proportionally increasing GPU resources. A persistent, highly available KV cache helps protect cached inference state while providing shared access across GPU nodes and clusters, supporting more resilient and storage-efficient AI services at scale.
Supermicro, IBM, and NVIDIA jointly validated the integrated architecture across high-concurrency and noisy-neighbor scenarios, combining NVIDIA Dynamo, IBM Storage Scale software, Supermicro Petascale servers and NVIDIA Spectrum-X networking. Supermicro's factory rack integration and on-site deployment services can reduce the deployment time of this solution from weeks to days.

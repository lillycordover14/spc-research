Netlist to Showcase CXL® NVvault™ Memory Family at SC26 Targeting KV-Cache Management, In-Memory Databases and Virtual Machines

-Designs explore intelligent memory tiering, data persistence and DDR4 reuse-
 
 
IRVINE, Calif., Nov. 16, 2026 /PRNewswire/ -- 
Netlist, Inc.
 (OTCQB: NLST), a leading innovator in advanced memory and storage solutions, today announced it will showcase three proof-of-concept (POC) designs from its CXL® NVvault™ memory family at SC26, with an emphasis on AI infrastructure and key-value (KV) cache management. The company will present the designs at the 
CXL Pavilion
, Booth 1218, November 17–19 at McCormick Place in Chicago.
 
 
 
 
Netlist, Inc.
 
 
 
"Our focus is on helping infrastructure teams more effectively manage, protect and expand memory," said Mario Martinez, Director of Marketing at Netlist. "Netlist's CXL NVvault family explores innovative approaches to AI KV-cache management while addressing the broader needs of memory-intensive computing. We look forward to discussing these architectures, customer requirements and how we support next-generation computing environments at SC26."
 
 
 
 
 
CXL
®
 NVvault™ Memory Family:
The three complementary designs address KV-cache management and memory expansion for in-memory databases, virtual machines, HPC and other enterprise workloads. They explore managing data across memory tiers, preserving critical information and extending the value of existing memory assets, with the goal of improving capacity, performance, data persistence and memory efficiency.
 
 
 
Intelligent KV-Cache Memory Tiering - CXL NVvault™-HM:
 a POC for intelligent tiering and high-capacity CXL memory expansion, combining DRAM as a high-speed cache with NAND-backed capacity. Tiering, telemetry and data migration are designed to manage hot, warm and cold data for AI infrastructure and KV-cache management, databases, analytics and other capacity-intensive workloads.
 
 
 
Persistent KV-Cache Memory — CXL NVvault™-PM:
 a CXL-attached non-volatile memory POC built on CXL Type 3 over PCIe Gen5. Designed to combine DRAM-class performance with persistence, it pairs low-latency DRAM with onboard NAND backup and an embedded energy source for power-loss protection of DRAM-resident data. It targets persistent, cache-coherent memory expansion for KV-cache management, AI/ML checkpointing, and accelerated database and HPC recovery.
 
 
 
DDR4 Reuse Memory Expansion - CXL NVvault™-D4
: a CXL-attached DDR4 memory expansion POC designed to extend existing DDR4 assets' value through reuse as expanded host memory, increasing capacity for in-memory databases, virtual machines, HPC and other enterprise workloads.

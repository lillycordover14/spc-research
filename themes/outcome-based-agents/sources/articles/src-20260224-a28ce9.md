[agent notes, not verbatim] Primary Claude blog post dated February 24, 2026. Companion post the same day covers finance plugins (separate record). TechCrunch covered the launch as Anthropic's 'enterprise agents program' on Feb 24 (not fetchable in this environment, so not quoted here).

Introduction: "Admins can now create private plugin marketplaces, with better control over plugins, connectors, and skills."

Admin and governance features: a new Customize menu consolidating plugins, skills and connectors; company branding; per-user provisioning; auto-install; control over plugin access ("Admins also get more control over what plugins their teams can access"); MCP controls; private GitHub repositories as plugin sources (private beta); org-specific marketplaces. "Additionally, we're adding OpenTelemetry support, letting admins track usage, costs, and tool activity across their teams."

Plugin templates: HR (people operations such as offer letters and performance reviews), Design, Engineering (standups, incident response, postmortems), Operations, Brand voice (by Tribe AI), Financial analysis, Investment banking, Equity research, Private equity, Wealth management. "Plugins are simple, portable file systems that you own."

New connectors: Google Workspace (Calendar, Drive, Gmail), Docusign, Apollo, Clay, Outreach, Similarweb, MSCI, LegalZoom, FactSet, WordPress, Harvey. Partner-built plugins: Slack by Salesforce, LSEG, S&P Global, Apollo, Common Room, Tribe AI.

Cross-app: Claude can run multi-step tasks across Excel and PowerPoint, passing context between them; research preview for all paid plans on Mac and Windows. "It's an early research preview that points toward Claude working across apps just like we do."

Customers and partners quoted: PwC ("Three waves have reshaped professional work: productivity tools, cloud and search, and now agentic AI."), Blank Metal ("What Anthropic built is so much better."), and Thomson Reuters CoCounsel Legal, described as a legal agent built on the Claude Agent SDK.

Availability: "All user experience updates for plugins are available to all Cowork users." No new pricing was stated.

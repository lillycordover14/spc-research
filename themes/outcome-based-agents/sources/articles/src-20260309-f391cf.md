[agent notes, not verbatim] Primary Microsoft Security blog post, March 9, 2026, by Vasu Jakkal, CVP Microsoft Security. Same-day posts on the Official Microsoft Blog ('Introducing the First Frontier Suite built on Intelligence + Trust') were not fetchable in this environment.

Key announcements: "Today we shared the next step to make Frontier Transformation real for customers across every industry" and "Agent 365 and Microsoft 365 E7: The Frontier Suite, generally available on May 1, 2026".

Agent 365: described as the control plane for observing, governing and securing agents, including those from ecosystem partners. "Without a unified control plane, IT, security, and business teams lack visibility into which agents exist". "Agent ID gives each agent a unique identity in Microsoft Entra, designed specifically for the needs of agents." Price: "Agent 365 will be generally available on May 1, 2026, and priced at $15 per user per month." Some capabilities in public preview; a runtime threat protection capability entered public preview in April 2026.

Microsoft 365 E7: "Microsoft 365 E7 includes Microsoft 365 Copilot, Agent 365, Microsoft Entra Suite, and Microsoft 365 E5". "It will be available for purchase on May 1, 2026, at a retail price of $99 per user per month."

Scale: "Microsoft Security capabilities help protect 1.6 million customers at the speed and scale of AI." (cited to FY2026 Q2 earnings call).

Not in this article: Copilot Cowork (announced in the Wave 3 materials the same day per search results, GA June 16; see separate record). Search-result snippets from Microsoft's licensing FAQ (not fetched) indicate no additional per-agent or per-instance charges in Agent 365; treat as unverified.

[agent notes, not verbatim] Primary Google Cloud blog post dated April 22, 2026, by Brian Delahunty (VP Engineering, Agents Platform) and Michael Gerstenhaber (VP Product Management, Gemini). Announced at Google Cloud Next '26; keynote filed separately. Search results (Google release notes, not fetched) state that Vertex AI is now part of Gemini Enterprise Agent Platform with product renames such as Agent Engine to Agent Runtime; this post itself calls it an "evolution of Vertex AI".

Portfolio: "Gemini Enterprise Agent Platform is our new developer platform and evolution of Vertex AI." The Gemini Enterprise app lets teams discover, create, share and run agents, built on Agent Platform and connected to enterprise data. Open partner ecosystem with third-party agents from Oracle, Salesforce, ServiceNow, Adobe and Workday.

"Gemini Enterprise is now an end-to-end system for the agentic era, built for agents that can execute complex, multi-step work processes." "The first wave of AI changed how we find information; the next wave is changing how we get work done."

Build: enhanced ADK with graph-based framework, ecosystem integrations, MCP support; Agent Studio low-code; A2A for interoperability. Scale: improved Agent Runtime, agent-to-agent orchestration, Memory Bank and Memory Profiles. Govern: Agent Identity (unique cryptographic ID per agent), Agent Gateway (secures agent-to-agent and agent-to-data interactions), Model Armor (prompt injection, tool poisoning, data leakage). Optimize: Agent Simulation ("stress-test your agents against real-world scenarios before they ship.") and Agent Observability.

For IT: "preventing AI sprawl without slowing down innovation." "Our secure-by-design architecture gives IT teams centralized control over their entire agent lifecycle." "Any agent built on Agent Platform can then be instantly surfaced in the Gemini Enterprise app for your employees to access."

App features: Agent Designer (no-code, schedule or trigger-based agents), Inbox ("Users can monitor active agents, adjust configurations, and receive real-time status alerts directly through email and chat"), Projects, Canvas, Agent Gallery ("Every partner agent in the gallery has been validated by Google Cloud to meet our requirements for security and interoperability.").

Not in the post: pricing, customer names, specific model names, Agent Registry.

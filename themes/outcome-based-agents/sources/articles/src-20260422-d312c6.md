[agent notes, not verbatim] Primary Google Cloud blog post, April 22, 2026: an adapted transcript of Thomas Kurian's Next '26 keynote. Companion product blog on Agent Platform filed separately.

Agent Platform pillars: build (ADK with graph-based framework, Agent Studio low-code, Agent Registry, Agent Marketplace, MCP support with Google Cloud services exposed as MCP), scale ("Agent-to-Agent Orchestration enables agents to seamlessly delegate tasks to one another", sub-second cold starts, long-running agents, secure sandboxes at 300 per second per cluster, Memory Bank and Memory Profiles, Agent Sessions), govern ("Agent Identity improves the security posture of your agents by ensuring every agent receives a unique cryptographic ID", Agent Gateway with Model Armor, anomaly detection, Agent Security dashboard), optimize (OTel-compliant Agent Observability, Agent Simulation, Agent Evaluation). Models include Gemini 3.1 Pro and Anthropic Claude Opus, Sonnet, Haiku, plus Claude Opus 4.7.

Domain agents: Customer Experience (shopping and food ordering agents, customer support agents, Conversational Insights, Agent Assist, Omnichannel Gateway, Universal Consumer Context, human-like voice); Security (Triage and Investigation Agent, Threat Hunting Agent, Detection Engineering Agent, Dark Web Intelligence, Wiz Red, Blue and Green agents); Data (Data Agent Kit, Deep Research Agent connected to BigQuery, Knowledge Catalog; "systems of action" framing); Productivity (Workspace agent).

Marketplace: partner agents from Atlassian, Box, Lovable, Oracle, ServiceNow, Workday deployable from Gemini Enterprise; Agent Gallery with Adobe, Atlassian, Lovable, ServiceNow. "Thousands of agents built by our partners are available in Google Cloud Marketplace."

Services: every major SI offers access; more than 330,000 consultants trained. "we are now sending teams of Google Cloud forward-deployed engineers to partner closely with teams from Accenture, Capgemini, Cognizant, Deloitte, HCLTech, PwC and TCS". Early model access for Accenture, BCG, Deloitte and McKinsey.

Numbers: 40% QoQ growth in Gemini Enterprise paid MAUs in Q1; nearly 75% of Google Cloud customers use its AI products; 330 customers processed over one trillion tokens in 12 months and 35 reached 10 trillion; first-party models process over 16 billion tokens per minute via API, up from 10 billion. Customers: GE Appliances 800+ agents; Virgin Voyages 1,000+ agents and 40% faster campaign creation; KPMG 90% employee adoption and 100+ agents in the first month; Macquarie 100,000+ team hours reclaimed; Signal Iduna 37% faster insurance answers; WPP thousands of agents; Deloitte security 60%+ analyst efficiency gain; UC Riverside 90% faster incident response.

Pricing: none stated in the keynote.

[agent notes, not verbatim] Primary Microsoft Security blog post dated May 1, 2026, by Nirav Shah, Rob Lefferts and Jason Roszak.

Availability and pricing: "Now generally available for commercial customers." "Agent 365 is now available in Microsoft 365 E7 or standalone at USD15 per user per month." A license covers each person who manages or sponsors agents or who uses agents to do work on their behalf.

Agent types: agents acting on behalf of users with delegated access (GA); background agents with their own access (GA); agents participating in team workflows with their own access (public preview).

Framing: "you can’t govern what you can’t see, and you can’t secure what you don’t understand".

Local and shadow agents: discovery of local agents on Windows devices starts with OpenClaw, with GitHub Copilot CLI and Claude Code planned next. Frontier program customers can see OpenClaw usage and use Intune policies to block it. "Many of these local and cloud-hosted agents run unmanaged and outside of traditional governance". "Starting in June 2026, Microsoft Defender will also provide asset context mapping for each agent" covering devices, MCP servers, identities and reachable cloud resources. Policy controls, runtime blocking and alerts planned for preview June 2026.

Multicloud: "the public preview of Agent 365 registry sync with AWS Bedrock and Google Cloud connections" for discovery and inventory; lifecycle actions (start, stop, delete) planned. Microsoft Foundry, AWS Bedrock and Google Gemini Enterprise Agent Platform are named as agent-building platforms.

Network: "Agent 365 extends Microsoft Entra network controls" to Copilot Studio agents and endpoint agents to restrict destinations, filter risky file movement and help block prompt-based attacks.

Ecosystem: partner agents fully configured for Agent 365 include Genspark, Zensai, Egnyte, Zendesk ("with no integration work by IT or security teams"); agent-factory agents from Kasisto, Kore and n8n; launch partners Adobe, NVIDIA, Zendesk, n8n, Kore.ai, Celonis.

Windows 365 for Agents: "now available in public preview (in the United States only)" as a managed environment for computer-using agents.

Not in the article: total agent counts, Anthropic or OpenAI integrations, per-agent pricing.

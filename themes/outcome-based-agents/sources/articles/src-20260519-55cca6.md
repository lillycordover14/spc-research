[agent notes, not verbatim] Primary Claude blog post dated May 19, 2026. The same four features were announced on stage at Code w/ Claude SF on May 12, 2026 (recap at claude.com/blog/code-w-claude-sf-2026-sf, which also announced doubled Claude Code rate limits and higher Opus API limits; Code w/ Claude London May 20-21 added self-hosted sandboxes in public beta and MCP tunnels in research preview per search results). Treated here as one launch to avoid duplication.

Dreaming (research preview): "Dreaming is a scheduled process in Claude Managed Agents that reviews agent sessions and memory stores", finds patterns and curates memories so agents improve over time; can update memory automatically or let you review changes; surfaces recurring mistakes, converged workflows and team preferences. Memory captures learning during a session; dreaming refines it between sessions. Access by request form.

Outcomes (public beta): write a rubric describing success; the agent works toward it. "A separate grader evaluates the output against your criteria in its own context window", identifies what needs to change, and the agent makes another pass. Works for objective requirements and subjective quality such as brand voice. "In testing, outcomes improved task success by up to 10 points over a standard prompting loop", largest gains on hardest problems; file generation improved 8.4% on docx and 10.1% on pptx.

Multiagent orchestration (public beta): "lets a lead agent break the job into pieces and delegate each one to a specialist" with its own model, prompt and tools; specialists run in parallel on a shared filesystem; persistent events so "The lead agent can check back in with other agents mid-workflow"; Console traces which agent acted, in what order and why.

Webhooks: define an outcome, let the agent run, get notified on completion.

Customers: Harvey uses dreaming to retain learnings such as filetype workarounds ("Completion rates went up ~6x in their tests."); Netflix platform team analyzes logs from hundreds of builds in parallel; Spiral by Every uses a Haiku lead agent delegating to Opus subagents with outcomes scoring drafts ("Only drafts that clear the bar are returned."); Wisedocs grades document reviews against internal guidelines ("Reviews now run 50% faster, while staying aligned with their team's standards.").

Availability: dreaming research preview; outcomes, multiagent orchestration and memory public beta. Pricing unchanged from Managed Agents launch (tokens plus $0.08 per session-hour).

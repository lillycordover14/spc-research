[agent notes, not verbatim] Primary Microsoft Copilot blog post by Charles Lamanna (EVP Copilot, Agents and Platform), June 16, 2026. Copilot Cowork was introduced with Wave 3 of Microsoft 365 Copilot in March 2026 as built with Anthropic (per search results).

Availability: "Today we're announcing the general availability of Copilot Cowork worldwide." Follows three months of Frontier preview. "Cowork is the fastest growing feature in the history of our Frontier program"; over half of the Fortune 500 uses it. Named customers: Accenture, Avanade, Capital Group, Koch, Zurich Insurance.

Differentiators: cloud hosting so tasks run when laptops are off; native Work IQ grounding; security inside the Microsoft 365 trust boundary; multi-model; lower cost. "Cowork is designed to be more accurate, more secure, and lower cost than other offerings." Internal testing: about 30 to 40% cheaper per prompt than Claude Cowork with its Microsoft 365 connector, both on Opus 4.8. "Our newest model, Cowork 1, will be a secure, fine-tuned model releasing in the coming weeks".

Pricing: "Copilot Cowork requires the Microsoft 365 Copilot User Subscription License (USL)." Usage billed in Copilot Credits based on model use, context retrieval, tool calls and runtime. "PayGo is priced at $0.01 per Copilot Credit." P3 offers committed-volume discounts. Tasks grouped as light, medium or heavy; four user personas; downloadable cost estimator. Billing starts June 16, 2026, with a grace period to July 1 for Frontier usage.

Cost controls: "Cowork is off by default." Spending limits at tenant, group and user level; usage alerts and reports; per-task cost visible to users.

Models: "At general availability, Copilot Cowork runs on Anthropic models, including Opus 4.8 and Sonnet 4.6." Frontier customers can use GPT 5.5.

Features: toggle in the M365 Copilot app; nine partner plugins now, eight more plus the Dynamics 365 suite coming; Edge browsing for Frontier users; audit logs, eDiscovery, Insider Risk Management, DLP coming.

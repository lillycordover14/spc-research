[agent notes, not verbatim] OpenAI post September 10, 2026: Agents API public beta. Lessons from scaling Codex and ChatGPT for Work: useful agents need a harness that manages context, uses tools efficiently, coordinates subagents, and infrastructure that runs reliably for days with environments for files, code and intermediate results. Same harness and infrastructure as Codex. Available to all developers; no additional fees, pay for tokens and tools. DevDay recap (September 29, 2026) adds computer use, Codex multi-agent capabilities, tool search, tool calling and context compaction; OpenAI runs underlying infrastructure.

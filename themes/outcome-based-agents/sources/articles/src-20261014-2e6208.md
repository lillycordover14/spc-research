[agent notes, not verbatim] Primary Claude resources article dated October 14, 2026 (title tag: 'Trace agents with OpenTelemetry on the Claude Platform').

Features: "every agent turn, model call, and tool use arrives in your observability tool as a standard OpenTelemetry trace". Traces cover agent turns, model calls, tool use and MCP server calls; each includes latency, token usage and IDs. "Claude traces follow the OpenTelemetry GenAI semantic conventions", so data from Claude and other providers can sit in the same dashboards. Any OTel tool accepting a standard OTLP endpoint works.

Rationale: "Trusting an agent with more access starts with tracing its model calls, tool use, and MCP server calls." "Review its traces, then widen its access as it proves reliable."

Availability: public beta. Managed Agents and the Messages API need a destination configured in the Claude Console; Claude SDKs export traces automatically.

Partners: observability (Grafana Cloud, Honeycomb, Sentry, Splunk); evaluation and LLM tooling (Arize AI, Braintrust, Datadog, Langfuse, LangSmith by LangChain, New Relic, PostHog); usage tracking (Databricks Unity Gateway for token usage by team and anomaly flags).

Customers: Foxglove analyzes agent interactions in PostHog; Ramp uses Langfuse traces to improve its agents; Sterling Labs streams traces into Langfuse ("Native OpenTelemetry export from the Claude Platform streams every trace straight in with no custom instrumentation", Hyon Lee, CTO); FloQast puts model calls in Grafana Cloud alongside accounting workflows ("Agents that touch a company's books have to show their work, the same way an accountant does.", Ankush Sharma).

Pricing: not stated. Context: Managed Agents (Apr 8) already had Console tracing; this adds export to third-party tools. Cowork admins got OTel usage and cost tracking on Feb 24.

[agent notes, not verbatim] Primary Claude resources article dated October 22, 2026. A Google Cloud blog post titled 'Expanding Claude availability and deployment choice on Google Cloud' appears on Google's blog index (not fetched).

Availability: Claude Models on Google Cloud (Anthropic managed) is GA with US and Global endpoints. "Anthropic operates the service and acts as the data processor." The Google-managed offering (Google as data processor) remains.

Features: full Claude API feature set with new features and betas on the same day as native: Claude Managed Agents (beta), code execution, computer use, agent skills, advisor strategy (beta), Files API, citations, web search and web fetch, MCP connector (beta), prompt caching, batch processing. Claude Console access for managing agents, monitoring usage and costs and per-workspace access.

Models: Claude Fable 5.1, Opus 5.5, Sonnet 5.5, Haiku 5.5. Fast Mode on Opus 5.5 GA: "Fast mode prioritizes speed, offering up to 2.5x faster output token generation" at $8 per million input tokens and $40 per million output tokens.

Billing: single Google Cloud invoice; usage draws down existing Google Cloud commitments; discounts must be arranged in advance with an account executive. Existing Google Cloud IAM credentials work.

Customers: Abacus.AI (Arvind Sundararajan, CTO: "Accessing new features on day one is important."; "Using our existing IAM set-up and knowing usage counts towards our Google Cloud commitment"); Triple Whale (Maksim Gorev: "we run Moby on Google Cloud on the same Claude API our team already builds on."; "Prompt caching is central to how we run Moby cost-effectively at scale").

[agent notes] Read-through: earlier in the window Google's Agent Platform already offered Claude models (Next '26 keynote lists Claude Opus, Sonnet, Haiku and Opus 4.7), but as a Google-managed model endpoint. This launch puts Anthropic's own harness (Managed Agents, skills, MCP connector, Console) inside Google Cloud procurement, so an enterprise can buy the lab's agent runtime with cloud commitment dollars. That is a direct contest between the lab harness and Google's own Agent Runtime on Google's marketplace.

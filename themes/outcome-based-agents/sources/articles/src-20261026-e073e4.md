NVIDIA unveils architecture for secure enterprise AI agents&nbsp;&nbsp;Engineering.com

[page text]
The design combines Vera Rubin infrastructure, Vera CPUs and BlueField DPUs to monitor agent behavior and enforce security policies.

NVIDIA today announced the 
NVIDIA OpenShell Reference Architecture
, which enables building, containing, observing and enforcing safe agents on enterprise infrastructure and edge systems.

The OpenShell Reference Architecture builds on the foundation of 
NVIDIA OpenShell
 secure runtime software, extending it into full-stack, industrial-scale infrastructure for agent development and operations.

It includes 
NVIDIA Vera Rubin
 infrastructure for running enterprise workloads, including closed and open models built with 
NVIDIA Nemotron
; 
NVIDIA Vera CPUs
 for operating agent harnesses; open source NVIDIA OpenShell software; and 
NVIDIA BlueField
 DPUs for running the 
NVIDIA Sentry
 unified security software framework that provides continuous out-of-band monitoring of agent behavior and in-silicon policy enforcement.

The OpenShell Reference Architecture is extensible to agents running at the edge across industries such as retail, healthcare, manufacturing, robotics, software development and telecommunications with 
NVIDIA RTX Spark
, 
NVIDIA DGX Spark
 and 
NVIDIA DGX Station
 systems.

Full-stack infrastructure built for agents

The OpenShell Reference Architecture features NVIDIA accelerated computing paired with software for secure agent operations.

NVIDIA Vera Rubin
, with NVIDIA Vera Rubin NVL72 infrastructure at its core, is 
fungible
 across pretraining, post-training and inference. For agentic workloads, NVIDIA Vera Rubin NVL72 systems deliver 30x higher throughput per megawatt.

NVIDIA Vera CPUs
 deliver 2x the performance of x86 processors with greater energy efficiency and run 
NVIDIA OpenShell
, which provides a secure runtime boundary for autonomous agents.

NVIDIA BlueField-4 DPUs
 continuously monitor agent behavior with 
NVIDIA Sentry
, built on 
NVIDIA DOCA
 software. BlueField and NVIDIA Sentry together provide in-silicon security enforcement — if an agent attempts to move outside its software boundary, NVIDIA Sentry quarantines and stops it in milliseconds. NVIDIA Sentry, powered by DOCA and running on BlueField-4, boosts agent capacity by up to 20%.

NVIDIA partners building secure agent deployments with OpenShell

NVIDIA is working with industry leaders building infrastructure, models and software to enable industries to safely deploy agents in production.

The OpenShell Reference Architecture runs on leading enterprise operating systems and container orchestration layers, including Linux and Kubernetes infrastructure powered by Canonical, 
SUSE
 and 
Red Hat
, as well as Microsoft Windows using Microsoft Execution Containers (MXC). It can run on cloud operating systems from Amazon Web Services, Google Cloud and Microsoft Azure.

Enterprises can run agents from model builders including Anthropic, Cohere, Google, Meta, OpenAI, Perplexity, Reflection and SpaceX Super Intelligence on OpenShell infrastructure. NVIDIA is also working with model builder partners on OpenShell deployments for advanced model research.

Serval’s AI Agents Just Landed A $3 Billion Valuation
Sequoia led a $150 million round for the enterprise automation startup pitching itself as a replacement for platforms like ServiceNow.
Finimize Newsroom
2 mins
What's going on here?

Serval, a San Francisco enterprise automation startup, raised $150 million in a Sequoia-led round at a $3 billion valuation, Reuters reported – about triple its reported $1 billion mark from December.

What does this mean?

Serval sells AI “agents”, meaning software that can take actions across other tools, to automate routine work. It’s starting in IT operations: managing employee access, troubleshooting, and keeping tabs on software and hardware inventory. CEO and co-founder Jake Stauch told Reuters the goal isn’t to bolt AI onto existing “systems of record” (the databases companies run on), but to replace platforms like ServiceNow; he said EV maker Lucid Motors sw..
ors switched from ServiceNow to Serval in 45 days. Reuters said the new money will fund Serval’s Catalyst product, which helps customers build and run automated workflows, signaling investors think AI-native software can compete directly with incumbents like ServiceNow and Workday. A big sticking point is control, since companies don’t want an automated tool making sensitive changes unchecked: Stauch said Serval separates an admin agent that builds workflows from an employee-facing agent that can only run pre-approved ones, with IT and security teams setting permissions and humans still signing off on higher-risk actions.

Why should I care?

For markets:
 
Lucid’s 45-day move off ServiceNow is the kind of proof point incumbents can’t ignore.

Serval’s pitch matters because it frames AI agents as a “rip-and-replace” option, not an extra software add-on. If migrations start to look like weeks rather than quarters, switching costs – the time, money, and disruption of changing core tools – feel lower. That changes procurement conversations: renewals stop being the default and start looking more like competitive re-bids, which can raise churn risk and increase discounting pressure. For subscription-heavy software companies, even small dents to retention can ripple into the valuation multiples investors are willing to pay, so case studies like Lucid’s tend to put a brighter spotlight on ServiceNow’s and Workday’s renewal dynamics.

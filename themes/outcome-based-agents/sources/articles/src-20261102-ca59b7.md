OpenAI is merging ChatGPT’s Chat and Work tabs on desktop

One tab will take you from idea to finished work, but ChatGPT and Codex will now share one usage allowance.

Abbas Jaffar Ali

Nov 2, 2026

ChatGPT and Codex will draw tokens from the same allowance pool.

Codex stays a separate section; rollout starts with select users, with no date given.

ChatGPT’s desktop app is dropping the split between its Chat and Work tabs, and ChatGPT and Codex will share a single usage allowance. 
TechCrunch’s Ivan Mehta first reported
 the change, which OpenAI announced in a user email.

Right now the app is split into ChatGPT and Codex sections, and the ChatGPT side then splits again into Chat and Work tabs. TechCrunch says the result “can be a confusing piece of software”. After the merge, you’ll be able to start with a rough idea and hand the finished job to ChatGPT without switching tabs.

OpenAI’s email describes the merged experience like this:

This will enable you to move from exploring an idea to having ChatGPT carry it through, all in one place. You can bring in your files and plugins and ask ChatGPT to build a website, create a presentation, or do things for you on the web, while reviewing and guiding its work.

Codex will remain a separate experience in the desktop app.

The catch is in the usage limits. Both ChatGPT and Codex will draw tokens from the same allowance pool, so chatting and coding will count against the same limit. OpenAI says most users won’t notice, but depending on usage and model, “some folks might need to wait for resets more frequently.”

OpenAI brought the 
5-hour cap on Work and Codex
 back for Plus subscribers on 25 August, while Pro kept unlimited access. In October, OpenAI’s 
Chrome extension started filling in forms
 in Work mode. In September, Anthropic 
merged Claude’s chat and Cowork into one screen
.

OpenAI hasn’t given a date. The merged tab will reach select users first for feedback, then roll out widely. It’s also unclear which plans will get it, how big the shared pool will be, or whether the web and mobile apps will follow.

Global AI audio company ElevenLabs on November 3 unveiled "Eleven Realtime," a speech-to-speech (STS) model that simplifies the process of building voice agents—previously requiring developers to separately combine individual technologies for speech recognition, conversational flow control, and speech synthesis—into a single model selection.

The model comes in two versions: "Eleven Realtime v1 Mini," focused on fast and natural conversation, and "Eleven Realtime v1 Max," specialized for handling complex tasks. It is offered through the voice chat agent platform "Eleven Agents" and a Realtime application programming interface (API).

Previously, building a natural-sounding voice agent required developers to individually select and combine multiple components, including speech recognition, voice activity detection, turn-taking, large language models (LLMs), and speech synthesis. The core of Eleven Realtime is that it integrates these functions into a single system, enabling agents to be built simply by choosing a model.

Both models support more than 90 languages, including Korean and Japanese, and let users select a desired voice from ElevenLabs' library of more than 17,000 voices. They also feature turn-taking, responsiveness to user interruptions, and the ability to call external tools. By simply changing the model selection according to the service's purpose, users can switch between Mini and Max.

The use cases are clearly divided. The Mini model is suited to services where fast responses are critical, such as AI assistants, educational tutors, and interactive characters in games and entertainment. The Max model focuses on tasks such as customer support that retrieves information according to defined procedures, lead qualification, and multi-step work that calls various tools.

Performance metrics were also disclosed. In an evaluation conducted last October by third-party evaluator Artificial Analysis, the Max model recorded 98.8% accuracy on "Big Bench Audio," which measures voice-based reasoning capabilities. The time from when a question ended to when the answer began was 0.57 seconds. On the "Full Duplex Bench," which measures responses to silence, turn-taking, interruptions, and backchanneling during conversation, the Mini model scored 95.8% and the Max model 94.1%, respectively.

The distribution method also ties into the existing platform. Eleven Agents users can create a new agent or select Eleven Realtime from the model selection menu of an existing agent. It can be deployed to phone, website, and contact center channels, and users can continue to leverage the existing platform's workflows, knowledge base, safeguards, testing, and monitoring features.

Developer accessibility was also a target. The Realtime API is compatible with OpenAI's Realtime API and connects via WebSocket. Developers already using the OpenAI Realtime API can switch immediately by changing only the connection target and model name in their code. However, at launch it does not support WebRTC.

ElevenLabs plans to target the enterprise voice agent market by emphasizing multilingual support, including Korean, and simplified deployment. A company representative said, "Through Eleven Realtime, which supports more than 90 languages including Korean, we plan to help South Korean companies and developers build voice agents that converse naturally with customers."

In the voice AI market, latency and development costs arising from the process of combining multiple components have been cited as obstacles to commercialization. ElevenLabs' simultaneous release of an integrated model and an OpenAI-compatible API is seen as a strategy to absorb existing voice agent development demand while also attracting developers considering switching from their own models. The 0.57-second response latency and the interruption-handling scores are metrics aimed directly at contact center automation demand, where real-time consultation and guidance are critical.

Apple is introducing two major Safari improvements with iOS 27.3, including a new Vertical Tabs layout and Adaptive Dark Mode for websites. Both features are available in the first developer beta released on November 3, alongside similar updates for iPadOS 27.3 and macOS Golden Gate 27.3.

The changes expand Safari’s existing customization options, making it easier to manage multiple websites and browse comfortably at night. Apple is also introducing new Siri controls that build on the 
automatic tab organization features introduced in iOS 27
.

Safari Gets a New Vertical Tabs Layout

Safari now supports Vertical Tabs, allowing users to arrange their open websites in a sidebar on the left instead of the traditional horizontal layout. By default, the sidebar displays website icons to save space, although users can expand it to show complete page titles.

The layout also supports existing 
Tab Groups and automatic topic organization
, along with pinned tabs and quick switching between groups.

To enable Vertical Tabs on iPhone, open 
Settings > Apps > Safari
 and select the new layout option. On iPad and Mac, users can also enable it through Safari’s View menu.

Adaptive Dark Mode Works on Websites Without Dark Themes

Apple is also introducing Adaptive Dark Mode, which automatically adjusts websites that lack native dark theme support. When users open a bright website with system Dark Mode enabled, Safari offers a 
Try
 button to preview the darker appearance.

According to 
Apple’s WebKit announcement
, the feature analyzes webpage colors and adjusts backgrounds, text contrast, gradients, logos, and vector graphics while preserving readability.

Apple explains that nearly 40% of webpage loads come from users browsing in Dark Mode, although only 10% of page loads support it.

Users can enable Adaptive Dark Mode across compatible websites or configure it individually. Safari leaves websites with existing dark appearances unchanged, while developers can control how their pages respond.

Siri Gets More Control Over Safari

Beyond the visual improvements, iOS 27.3 introduces Siri actions for organizing, moving, and closing tabs, managing Tab Groups, and clearing browsing history for specific websites or periods.

These Siri features require an Apple Intelligence-compatible device. Expanded webpage awareness, including understanding content across inactive tabs, is planned for a later beta.

The new Safari features are currently available to developers testing iOS 27.3, with a public release expected in December 2026.

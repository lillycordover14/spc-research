Most AI coworker products are vendor locked. They pick the model, host the data, and write the rules. CopilotKit is taking the opposite route. 
OpenBot 1.0
, was released November 9th, an 
MIT-licensed
, self-hostable agent workspace. What sets it apart is, a company brings their own models, agents and infrastructure. Governance is fully baked in, and every Bot action is checked against a policy before it runs.

What is OpenBot?

OpenBot is a modular agent workspace from 
CopilotKit
, the team behind the AG-UI protocol. You give a Bot a task and watch it work. You review findings, interact with results and approve next steps in the same conversation.

Each Bot gets 
a computer of its own
. That is a container with its own Chromium browser, logins and files. It reaches only the tools you grant. Answers can come back as charts, checklists, tables and cards. In the new v1.0, Bots now reply in Markdown by default and draw components when they help.

How does the governance gateway work?

Every browser click, file write, MCP tool call and component goes through one gateway. It evaluates a CEL policy, 
writes the audit row first
, then acts. Deny rules run before allow rules, and a broken rule refuses rather than opens.

On top of that, the
 
business tier
 
adds:

Single sign-on and SCIM sync for users and groups. The README documents Google, Microsoft (Entra) and Okta, plus SAML and OIDC.

On-behalf-of tokens, usually scoped to a subset of the person’s permissions.

Tool grants per Bot, per role or per person, with access requests to an admin.

Policies that block actions or route sensitive work to a human for approval.

Spend visibility per Bot, role, team or person, plus daily, weekly or monthly token limits.

A full audit trail with SIEM export, multi-tenancy and an admin plane.

EU AI Act content labeling, retention controls and deletion on request. CopilotKit itself holds SOC 2 Type II.

Which agents and models can you bring?

Any agent that speaks 
AG-UI
 plugs in. The 
site lists
 8 frameworks: Claude Agent SDK, OpenAI Agents SDK, LangChain, Google ADK, Mastra, AWS Strands, Microsoft Agent Framework, CrewAI. The repo also ships Agno, AG2, LlamaIndex and Pydantic AI examples.

For models, teams can use OpenAI, Claude, Gemini or Grok through existing subscriptions or API keys. Open models such as Kimi, DeepSeek, Qwen, Nemotron and Mistral are also supported. Sandboxes, MCP hubs and browsers are swappable lanes.

What is new in OpenBot 1.0?

Desktop app
 for Mac (Apple Silicon and Intel) and Windows, with signed updates and backup before upgrade.

Teach a Bot:
 record a task once, and Learning turns the recording into a reusable skill you review.

Multiple accounts per app
 through 
Composio and Arcade
, with approval rules saved per account. Composio alone brokers a few hundred apps.

Orchestration:
 one Bot can hand work to specialist Bots, within admin-granted pairs and depth limits.

Early access
 for iOS, Android, Slack (through OpenTag) and Microsoft Teams.

How do you deploy it?

Personal use runs locally, with workspace data and API keys stored on your machine. For companies, 
1 Helm chart
 deploys into AWS (EKS), Azure (AKS), Google Cloud (GKE) or any Kubernetes cluster.

Pricing
 is free for personal projects. OpenBot for Business costs up to $29 per active user per month. A 5% charge applies only to model spend above $5,000 per month. The Annual plan adds air-gapped deployment and 24/7 support. Forward-deployed engineers help teams roll it out.

Example use cases

Ticket triage:
 route new support tickets, then post to Slack after a person approves.

Expense review:
 check each claim line against policy and flag overages.

Ops workflows:
 find problems and draft fixes for a human to approve.

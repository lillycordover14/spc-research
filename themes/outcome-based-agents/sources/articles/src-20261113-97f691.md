LangChain raised $300 million at a $3 billion valuation to fund its agent governance platform LangSmith.
Workday cut new agent deployment time from five months to under a day using LangSmith.
LangSmith serves over 7,000 organizations and centralizes control of models tools and data.
 

LangChain 
announced on November 13, 2026
 that it raised $300 million in a Series C round at a $3 billion valuation. Existing investor CapitalG led the financing.
The capital backs LangChain’s work on 
LangSmith
, a platform for operating, improving and governing agents regardless of the framework used to build them. Its stated mission centers on letting enterprises choose their models, control data and infrastructure, improve agents continuously and apply governance for secure operation at scale.
The round included significant participation from new investors GIC and DFJ Growth and existing investors IVP and Sapphire Ventures. Salesforce Ventures, Insight Venture Partners, QuantumLight and MongoDB Ventures also joined, while Sequoia, Amplify and Benchmark increased their participation.
LangChain expects agents built for specific domains to become standalone products and internal operational tools, differentiated by knowledge, data and user experience, with control of those systems forming the basis for lasting competitive advantage.
LangSmith Adoption and Customer Results
LangChain reports a LangSmith user base of more than 7,000 organizations. Its examples range from startups Harvey, Rippling and Listen Labs to Fortune 500 companies NVIDIA, Toyota and Salesforce. At Clay, the platform tracks hundreds of millions of agent runs each month and supports agent improvement. Workday uses LangSmith for organization-wide operation and governance, and cut the deployment time for a new agent from five months to under a day.
Those deployments illustrate why LangChain groups monitoring and governance with deployment: a high-volume agent operation needs visibility after launch, while a large organization also needs a shorter, controlled path into production.
Runtime, Improvement and Governance
LangSmith’s foundation is organized into Agent Runtime, Agent Improvement and Agent Governance. Agent Runtime covers the path from agent architecture to production infrastructure. Development teams use Deep Agents, LangGraph and LangChain to retain model choice and decide how context is managed. Secure, scaled deployment runs through LangSmith Agent Server and Sandboxes in either cloud or customer environments, while LangSmith Managed Agents and Fleet offer a fully managed route to production.
Agent Improvement pairs measurement with automated remediation. LangSmith Observability and Evaluation expose agent behavior and assess quality. LangChain says LangSmith Engine, its in-platform agent, looks for errors, produces code and prompt corrections, and checks production traffic for regressions. LangSmith Fine-Tuning helps teams convert agent traces into training data that can be used to tune and evaluate specialized models.
The governance pillar centralizes control of models, tools and data. Teams can use the LLM and Tool Gateways to set model budgets and fallback behavior, safeguard sensitive information, and manage tool access and authentication across teams and agents.
Next LangSmith Capabilities
LangChain
 has scheduled a release event for November 20, 2026, where it plans to share several additional LangSmith capabilities built on this foundation.
The central question for those releases is whether they make high-performing agents easier to build while preserving customers’ control over models, data, infrastructure and governance.

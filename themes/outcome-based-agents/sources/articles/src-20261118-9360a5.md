Samsung introduced Privacy display with the Galaxy S26 Ultra, and the feature is expected to return with the Galaxy S27 Ultra, as well as expand to the Galaxy S27 Pro. What’s also great is that Samsung keeps improving it, and with the latest One UI beta, the feature becomes even more dialed in. Those who have experimented with it already know that it can be automatically activated when specific apps are open, when a PIN, pattern, or password is being entered, or when notifications pop up.

As shared by 
@smasithick on X
, the changelog for One UI 9.5 lists all the improvements coming to Privacy display. It can now automatically turn on when you open private albums in the Gallery, use Secret mode in the Samsung Browser, or visit locked notes in Samsung Notes. Furthermore, the notifications panel and Recent apps pages are also covered by Privacy display if they include an app that is part of the privacy list.

Privacy display has become a sought-after feature, and 
other brands
 have already started offering it with their flagships. As Samsung keeps adding new functionality, others are expected to do the same, if they don’t already. Regardless, it’s great to see Samsung’s continued investment in a feature that it pioneered.
 
There are some other privacy-related improvements in One UI 9.5 beta, such as locking individual apps, seamless fingerprint and face recognition at the same time for features that support both, as well as a cleaner UI for fingerprint and face registration.

Tashreef Shareef / MakeUseOf
Credit: Tashreef Shareef / MakeUseOf

As mentioned earlier, One UI 9.5 beta is available to those enrolled in the beta program. Of course, the Privacy display improvements will only be valid for Galaxy S26 Ultra owners. It should also be noted that since this is beta firmware, it is possible that some of these updates and improvements don’t make it to the final release.

Anritsu’s Tensor VNA: Industry First AI-Enabled VNA with Top-Notch RF Performance

                            Article By : Anritsu                                                    

 Category :  Test & Measurement
 

                                    2026-11-27                                

                                        (0) Comments
                                    

                                        Ask question of embedded
                                    

                                Anritsu’s Tensor VNA pairs a one-source-per-port architecture and powered by Anritsu Artificial Intelligence (AAI) helping users set up faster, measure more and test complex devices on a single platform.                            

Characterizing a modern amplifier, mixer or high-speed cable means reconnecting the same device several times, adding external signal generators and test sets, and spending hours on calibration. Anritsu’s Tensor Vector Network Analyzer is built around cutting that overhead. It comes in 2-port and 4-port models covering 10MHz to 26.5GHz or 43.5GHz.

Fewer setup changes for amplifier and mixer tests

On most VNAs, the RF measurement ports share one internal signal source, so multi-port devices that need simultaneous signal driving require either rewiring or adding external equipment. Tensor gives each port its own independently controlled source. In practice, a 2-port Tensor VNA can run a two-tone intermodulation distortion (IMD) measurement on an active device with no external signal generator. Two-tone tests are sensitive to the tones leaking into each other, and separate sources help keep the distortion you see coming from the device rather than from the test setup. Meanwhile, a 4-port Tensor VNA can measure 2 DUT together.

The one-source-per-port architecture also benefits frequency translation devices like mixers. For mixers measurement, Tensor VNA independent sources can be set to different frequency ranges to match the mixer’s RF, IF and LO operating ranges. Together with VNA additional internal local oscillator, Tensor VNA supports more complex scenarios, including Vector mixers, multi-stage mixers and IQ mixers, with magnitude and phase measurements that need no additional reference mixer.

Several hardware features further reduce setup effort. Built-in bias tees across the full frequency range let users power an active device without an external bias network, which would otherwise add mismatch and calibration error. Tensor VNA port couplers also provide exceptional power handling capability up to 2W, so high-power parts can be tested without extra attenuators. Along with source high power output, and superior noise floor, Tensor VNA dynamic range could achieve as high as 147dB above 2GHz, which helps when you need to see very weak signals.

On the software side, Tensor VNA provides a user-friendly GUI and measurement features. Conventionally, gain compression measurement with VNA is a power sweep on individual frequency point. Tensor VNA offers a unique Multi Frequency Gain compression (MFGC) across several frequencies to measure the gain compression point in one measurement setup and output a results table for simple processing. Tensor VNA also offer wizard mode which are DUT parameter centric, to guide user to easily configure the VNA for complex amplifier and mixer tests.

Multi Frequency Gain Compression (MFGC) feature

World First AI-Enabled VNA

The built-in assistant, Anritsu Artificial Intelligence (AAI), takes instructions in plain language. Now a new engineer or students can just ask for a mixer measurement and get recommendation on connections and settings, along with fundamental knowledge explanation. The VNA can then configure itself to be ready for measurement. It can also generate automation code with the corresponding SCPI commands and help diagnose measurement problems.

The Tensor AAI can run on the instrument with no internet connection, so it can be used in labs with restricted networks, such as some mission critical or security sensitive environments. The AAI can also run on internet, offering more advanced capability.

Higher frequencies and faster calibration

For work above 43.5GHz, Anritsu offers own millimeter-wave modules cover 54GHz to 220GHz in a single banded sweep without a separate test set. Various third-party waveguide modules reaching 1.1THz can be supported as well.

Along with Tensor VNA, Anritsu also launches an electronic calibration unit UltiCal, that can perform a full 4-port calibration to 43.5GHz in under two minutes, which cuts the time spent on manual calibration standards. UltiCal is also the industry first electronic calibration unit capable up to 43.5GHz with full 4-port calibration capabilities.

UltiCal: Industry first 4-port 43.5 GHz electronic calibration unit

Testing cables and interconnects at volume

Testing a 16-lane high-speed cable with a four-port VNA takes more than two and a half hours of manual reconnection, and each reconnection wears the connectors. Combining Tensor with a switch matrix and Anritsu’s ATS software automates routing, calibration, measurement and reporting, Tensor VNA offers a superior and exceptionally fast environment to measure high speed cables and interconnects.

Focus on your design, not the setup 

Taken together, Tensor VNA features target the usual time sinks in RF test: rewiring, external equipment, calibration and setup. Let Anritsu Tensor VNA take the heavy load of complicated measurement setup scenario and testing time, so your team can focus on your device performance and design.

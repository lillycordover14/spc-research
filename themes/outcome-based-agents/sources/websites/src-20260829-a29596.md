Overview
Kosmos is built for research questions that are too broad for a single literature search or one-off analysis. It can review large bodies of scientific literature and patents, work with uploaded or public datasets, write and run code, branch into parallel investigations and assemble the evidence into an auditable research report.
The current system has evolved from the original one-prompt Kosmos into a persistent, collaborative code-writing agent. Researchers can discuss the approach, steer the work while it runs and ask for progress artifacts rather than waiting for a single final answer. Edison positions it primarily for biopharma R&D and advanced academic research.
Kosmos is not a general-purpose science chatbot. Access to the newest version is being rolled out through an application process, current subscription pricing is not publicly posted, and its findings require expert review and experimental validation before they can support scientific or clinical decisions.

Capabilities
Kosmos searches and reads large research collections, including figures and tables, and links conclusions back to supporting passages.
It can retrieve data from scientific repositories, work with supplied files and write analysis code in isolated cloud workspaces.
A structured world model helps the system retain research context, propose explanations and update its working view as analyses produce evidence.
Kosmos can delegate literature searches and other scientific tasks to subagents while sharing a persistent project filesystem.
The current version can discuss the plan, receive feedback during an investigation and create progress websites or other research artifacts.
Edison describes collaboration through Slack, Microsoft Teams and email for research groups and enterprise deployments.
Process
- Step 1 Define one consequential objective Choose a focused scientific question that genuinely requires iterative literature review, data analysis and hypothesis testing.
- Step 2 Prepare context and data Explain experimental design, assumptions and column meanings, then provide quality-controlled files or identify relevant public sources.
- Step 3 Agree on an investigation plan Discuss likely analyses, useful evidence and validation criteria before allowing the agent to branch into longer-running work.
- Step 4 Steer the active research Review progress, correct domain assumptions and redirect analyses that are scientifically unhelpful.
- Step 5 Audit and validate Trace conclusions to source passages and code, reproduce critical analyses, and validate meaningful findings with independent experts or experiments.

Assessment
- Combines literature, patents, public data and private analysis in one research process
- Designed for deeper and longer-running work than a standard research chatbot
- Provides traceability from conclusions back to source passages and analysis code
- Persistent workspaces and parallel subagents support complex investigations
- Interactive steering lets domain experts correct course before the work is finished
- The newest Kosmos experience is not open self-serve software for every visitor

- Edison says Kosmos can pursue rabbit holes or statistically significant but scientifically irrelevant results
- Useful results depend heavily on a well-scoped objective, scientific context and properly prepared data
- Outputs must be reproduced and validated by qualified researchers before high-stakes use
- Long-running investigations can require substantial compute, time and expert oversight

Questions
Kosmos is Edison Scientific's AI scientist for long-running research. It combines scientific literature and patent review, data retrieval, code execution, analysis, hypothesis generation and iterative investigation.
Edison is accepting applications for the new Kosmos and says academic research groups are being prioritized as access expands. The older Kosmos interface remains in the public Playground only for a limited transition period.
Edison has ended its original Founding Kosmos subscriptions and has not published prices for the upcoming plans. The original $200-per-run launch price should therefore not be treated as the current offer.
Kosmos can work with uploaded scientific datasets and retrieve data from major public repositories. Edison recommends clear labels, experimental context and quality-controlled data rather than raw files that still need basic processing.
Instead of returning a quick answer, Kosmos can run a persistent research workspace, read large evidence collections, write analysis code, branch work across subagents and update hypotheses over time.
Its traceable sources and code make auditing easier, but they do not make every conclusion correct. Edison explicitly warns that Kosmos can follow unhelpful paths, so researchers need to reproduce analyses and validate findings independently.
No. Kosmos is a scientific R&D system, not a consumer medical adviser. Clinical or treatment decisions require qualified professionals, validated evidence and the appropriate regulatory process.
Bottom line
Kosmos is one of the more ambitious AI-for-science systems because it attempts to connect evidence review, computation and iterative discovery in a single persistent workflow. That makes it potentially valuable for well-resourced research groups with consequential questions and strong validation practices. It is excessive for ordinary paper search, and access uncertainty plus the need for expert oversight make it a specialist R&D tool rather than a general research assistant.

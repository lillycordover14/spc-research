This record uses AWS's own GitHub artifacts instead: the aws-sdk-ruby changelog for the bedrockagentcorecontrol gem (entries generated from AWS API releases) and the AWS agent-toolkit-for-aws reference on AgentCore Harness. Confidence is med because these are developer artifacts, not launch posts; dates are SDK release dates, which typically match API launch days. Third-party GitHub mirrors of AWS What's New (not used for facts) also reported a next-generation AgentCore Runtime in September 2026 and AgentCore payments GA in August 2026.

2026 AgentCore control-plane milestones (verbatim where quoted):
- 2026-03-03 (1.25.0) Policy: "Support for AgentCore Policy GA".
- 2026-03-10 (1.27.0) Runtime: first-class AG-UI protocol support.
- 2026-03-27 (1.33.0) Evaluations: "Adds support for custom code-based evaluators using customer-managed Lambda functions."
- 2026-04-02 (1.35.0) Gateway: three-legged OAuth and predefined MCP tool schemas.
- 2026-04-09 (1.37.0) Registry: initial CRUDL release for the AgentCore Registry Service.
- 2026-04-22 (1.39.0) Harness: "Adds support for Amazon Bedrock AgentCore Harness control plane APIs" for managed agent loops.
- 2026-04-29 (1.41.0) configuration bundles: versioned, immutable agent configuration snapshots.
- 2026-04-30 (1.42.0) Identity on-behalf-of token exchange; long-term memory metadata.
- 2026-05-04 (1.43.0) "Amazon Bedrock AgentCore gateways now support MCP Sessions and response streaming from MCP targets."
- 2026-05-07 (1.45.0) Payments: "Launching AgentCore payments - a capability that provides secure, instant microtransaction payments for AI agents" covering x402 processing, limits and third-party wallets.
- 2026-05-21 (1.48.0) Evaluations: "Adds dataset management APIs for creating, versioning, and managing evaluation datasets."
- 2026-05-28 (1.50.0) Harness: "Added Harness support for LiteLLM model configuration for third-party model providers." plus S3 and Git skill sources and Responses API format.
- 2026-06-17 (1.54.0) Gateway: "AgentCore Gateway now supports inference targets to LLM providers".
- 2026-08-06 (1.63.0) Gateway rate limits and Runtime instances (EC2-based capacity providers).
- 2026-08-17 (1.65.0) Evaluations: "Adds implementations of third-party evaluators".
- 2026-08-19 (1.66.0) Memory: "AgentCore Memory now supports Flexible Namespaces".
- 2026-09-03 (1.69.0) Identity consent portal APIs.
- 2026-09-15 (1.72.0) Runtime platform version selection.
- 2026-09-21 (1.74.0) Harness: "Amazon Bedrock AgentCore Harness now supports lifecycle hooks for invocations and tool calls" with Lambda, SNS and EventBridge targets; custom base endpoint for OpenAI-compatible models.
- 2026-10-12 (1.78.0) Memory: "AgentCore Memory now supports configuring Long-Term Memory Time-to-Live (TTL) on Memory Strategies."
- 2026-10-22 (1.83.0) Gateway: "Adds model-based routing and fallback to AgentCore Gateway rules." and multi-dimensional rating scales for LLM-as-a-Judge evaluators.

AgentCore Harness (AWS agent-toolkit reference): "AgentCore Harness is a **managed agent loop**: you declare what the agent is (model, system prompt, tools, skills, memory, limits) as configuration" and AgentCore runs the reasoning, tool-call and response cycle, powered by Strands Agents. "Each session runs in an **isolated, stateful microVM** with its own filesystem and shell." Models: "Bedrock (Converse), OpenAI, Google Gemini, and any LiteLLM-compatible provider (including self-hosted endpoints)." The doc installs the CLI from a preview npm channel and states no pricing.

Cross-reference: Microsoft's Agent 365 (May 1) added registry sync with AWS Bedrock in preview (separate record).
